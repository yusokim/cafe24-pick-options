# 카페24 상품상세 골라담기 옵션

카페24 베이직 스킨의 상품상세 페이지에 골라담기 옵션 UI를 추가한 과제 프로젝트입니다. 커스텀 화면은 옵션 선택 경험만 제공하고, 선택상품 생성·수량·가격·장바구니·바로구매는 카페24 기본 구매 로직을 그대로 사용합니다.

## 적용 URL

- [테스트 상품 상세페이지](https://yusokkim.cafe24.com/product/%EA%B3%A8%EB%9D%BC%EB%8B%B4%EA%B8%B0-%ED%95%9C%EB%81%BC%ED%86%B5%EC%82%B4-%ED%86%B5-%EB%8B%AD%EA%B0%80%EC%8A%B4%EC%82%B4-18%EC%A2%85/11/category/24/display/1/)
- 테스트 상품번호: `11`

## ① 옵션 UI 구현 방식

- PC에서는 상품 정보 영역 안에 카드형 옵션 목록을 표시합니다.
- `767px` 이하에서는 같은 데이터를 바텀시트로 렌더링합니다. 구매 버튼을 누른 시점에 선택상품이 없으면 바텀시트가 열립니다.
- 옵션별 선택 상태, 가격, 할인율, 뱃지, 선택 가능 개수를 표시합니다.
- 기본 텍스트 버튼 옵션 행은 CSS로만 숨기며 DOM과 카페24 이벤트는 삭제하지 않습니다.
- 바텀시트는 열림/닫힘, ESC, 포커스 이동을 처리하고, 선택상품이 많아도 선택 영역만 스크롤됩니다.

## ② 외부 설정 JS 구조

상품별 화면 데이터와 카페24 옵션값 매핑은 [`product/detail/config/catalog.js`](product/detail/config/catalog.js)에 분리했습니다.

```js
11: {
  enabled: true,
  groups: [{
    id: 'pack-10',
    label: '10개입',
    optionValues: ['10개입_1', '10개입_2'],
    maxSelectable: 2,
    displayPrice: '24,700원',
    summaryPrices: ['24,700원', '49,400원'],
    discountRate: '(25% 할인)',
    unitPrice: '1개 : 2,470원',
    badge: {
      label: '가장 많이 사요',
      color: '#ff6433',
      backgroundColor: '#fff0eb'
    }
  }]
}
```

- 키는 `product_no`이며, 상품마다 독립 설정을 추가할 수 있습니다.
- `optionValues`의 순서가 수량별 카페24 suffix(`_1`, `_2`)와 대응합니다.
- 노출 문구·뱃지·색상·가격·할인율·선택 제한은 설정 파일에서 바꿉니다. `summaryPrices`는 선택 카드의 표시 가격이며, 최종 결제 금액은 카페24가 계산한 값을 사용합니다.
- 재고, 최종 결제금액, 장바구니·주문·계정 정보 등 구매 로직 또는 민감 정보는 설정에 두지 않습니다.

## ③ 카페24 옵션과 동기화한 방식

[`cafe24-product.js`](product/detail/adapters/cafe24-product.js)는 카페24 DOM을 다루는 어댑터입니다. 다른 모듈은 카페24의 구체적인 선택자나 구매 로직을 직접 알지 않습니다.

1. 카드에서 `x개입`을 처음 선택하면 해당 그룹의 `_1` 기본 텍스트 버튼을 클릭합니다.
2. 카운터를 올리거나 내릴 때는 기존 suffix의 카페24 삭제 버튼을 클릭한 뒤 목표 suffix 하나만 선택합니다. 예: `10개입_1 → 10개입_2`.
3. 선택상품 목록의 DOM 변경을 관찰해 커스텀 카드 상태를 다시 계산합니다.
4. 동기화 작업은 전역 큐로 한 번에 하나씩 처리해 빠른 입력에서도 카페24 선택상품 생성·삭제 순서를 보존합니다.

따라서 동일 개입수의 `_1`, `_2`가 동시에 남아 가격이 중복 계산되지 않으며, 카페24가 생성한 선택상품·총금액·장바구니·바로구매 흐름을 사용합니다.

## 파일 구성

- `product/detail/option-picker.js`: 초기화와 구매 버튼 연동
- `product/detail/config/catalog.js`: 상품별 공개 노출 설정과 옵션값 매핑
- `product/detail/adapters/cafe24-product.js`: 카페24 DOM·이벤트 어댑터
- `product/detail/services/selection-reconciler.js`: suffix 전환과 선택 상태 동기화
- `product/detail/ui/`: PC 카드 및 모바일 바텀시트 뷰
- `product/detail/option-picker.css`: 옵션 UI 스타일
- `product/detail/product-detail-responsive.css`: 상품상세 공용 반응형 레이아웃
- `product/detail/INTEGRATION.md`: 스마트디자인 적용 경로와 삽입 위치

## 적용 및 검증

1. 테스트 상품을 독립 선택형·텍스트버튼·필수옵션으로 설정하고 suffix 옵션값을 등록합니다.
2. `INTEGRATION.md`에 따라 CSS·JS 파일, 옵션 행 스니펫, 모듈 로드 태그를 스마트디자인에 반영합니다.
3. 저장한 스킨을 대표 디자인으로 설정합니다.
4. 로그아웃 시크릿 창에서 위 스토어프론트 URL을 열어 아래 체크리스트를 기준으로 확인하고, 동기화·중복 방지·선택 제한·활성 상태는 짧은 화면 녹화로 남깁니다.

### 녹화 증빙 권장 항목

- 커스텀 카드 선택 후 카페24 선택상품 행이 생성되고 활성 상태가 갱신되는 장면 (#2, #7)
- 같은 개입수를 반복 선택·삭제·재선택해도 중복 suffix가 남지 않는 장면 (#3)
- `_1`, `_2` 제한에 도달해 `+` 버튼이 비활성화되는 장면 (#4)

## 제한 사항 및 후속 개선

- 맛 선택 패널은 과제 우선순위에 따라 아직 구현하지 않았습니다.
- 현재 어댑터 선택자는 테스트한 베이직 스킨의 옵션·선택상품 DOM을 기준으로 합니다. 스킨 구조가 다르면 어댑터의 선택자만 확인·조정해야 합니다.
- 실제 운영몰이 아닌 테스트몰에서만 검증합니다.
